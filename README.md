## Focus

- **Native Windows software** — WinUI 3 and WPF applications with a calm, precise visual language.
- **Typography** — a proprietary type family designed from scratch, with a deterministic build pipeline.
- **Operational tooling** — logistics and route-planning software that runs locally.

## Selected work

| Project | Description | Stack |
| --- | --- | --- |
| **Atreptos** | Brand system, landing site and identity assets | HTML · CSS · JavaScript |
| **Lipsis** | Media downloader for Windows | WinUI 3 · .NET 8 · C# |
| **Oiax** | Remote control for LG webOS televisions | WinUI 3 · .NET 10 · C# |
| **Chartis** | Logistics and route-planning workspace | Python · JavaScript |
| **Graphe** | Proprietary type family and release pipeline | Python · fontTools · UFO |
| **Kare** | GPU benchmark analysis for Windows ([Microsoft Store](https://apps.microsoft.com/detail/9P49TT4BJ798)) | WPF · .NET 10 · C# |

## Principles

- **Local-first.** Tools run on the machine they serve; data stays where it belongs.
- **Deterministic.** Builds and releases are reproducible from source.
- **Original by design.** Every glyph, token and component is created for the family, not copied.
- **Small and precise.** One clear purpose per application.
